# PRD: 스타트패키지 모바일 반응형 최적화

**버전**: 1.0
**작성일**: 2025-12-09
**상태**: 기획 중

---

## 1. 개요

### 1.1 프로젝트 배경
스타트패키지는 세무사/회계사 창업 지원 플랫폼으로, 사용자(수강생)가 브랜딩 자료를 제출하고 제작 현황을 추적하는 시스템입니다. 현재 대부분의 사용자가 **모바일 환경**에서 서비스를 이용하고 있으나, UI가 데스크탑 중심으로 설계되어 모바일 사용성이 떨어집니다.

### 1.2 목표
- 모바일 퍼스트 반응형 UI 구현
- 터치 친화적 인터페이스
- 모바일에서의 핵심 기능 접근성 개선
- 페이지 로딩 성능 최적화

### 1.3 범위
- **사용자 페이지** (클라이언트): 최우선
- **관리자 페이지**: 태블릿/데스크탑 중심 (최소 반응형)

## 3. 상세 요구사항

### 3.1 공통 요구사항

#### 3.1.1 브레이크포인트
```
Mobile:  320px ~ 767px  (기본)
Tablet:  768px ~ 1023px
Desktop: 1024px+
```

#### 3.1.2 터치 타겟
- 최소 터치 영역: 44px × 44px
- 버튼 간격: 최소 8px
- 폼 입력 필드 높이: 최소 48px

#### 3.1.3 타이포그래피
- 모바일 본문: 16px (확대 방지)
- 모바일 제목: 20px ~ 24px
- 줄 높이: 1.5 이상

#### 3.1.4 네비게이션
- 모바일: 하단 탭 바 또는 햄버거 메뉴
- 사이드바 → 슬라이드 오버 또는 숨김

### 3.2 페이지별 상세 요구사항

#### 3.2.1 대시보드 홈 (`/dashboard`) - P0

**현재 문제점:**
- 알림 카드가 가로로 나열되어 스크롤 필요
- 내 정보 카드와 진행 현황이 2열 그리드로 좁게 표시
- 제작 진행 현황 카드가 작게 표시

**개선 방향:**
```
[모바일 레이아웃]
┌─────────────────────┐
│    환영 메시지       │
│    D-Day 카운트      │
├─────────────────────┤
│  📢 알림 영역        │
│  (스와이프 가능)     │
├─────────────────────┤
│  📋 내 정보          │
│  (풀 너비 카드)      │
├─────────────────────┤
│  📊 자료 제출 현황   │
│  (진행률 바)         │
├─────────────────────┤
│  🏭 제작 진행 현황   │
│  (세로 스택 카드)    │
├─────────────────────┤
│  📅 마케팅 지원      │
│  (기간 카운트다운)   │
└─────────────────────┘
```

**구현 항목:**
- [ ] 알림 카드 → 가로 스와이프 캐러셀
- [ ] 2열 그리드 → 1열 세로 스택
- [ ] 카드 패딩/마진 조정
- [ ] 진행률 바 모바일 최적화
- [ ] 플로팅 액션 버튼 (자료 제출 바로가기)

**개선 방향:**
```

├─────────────────────┤

├─────────────────────┤

│   (풀 너비)         │

└─────────────────────┘
```

**구현 항목:**
- [ ] 탭 → 스텝 진행 바 (상단)

## 4. 기술 구현 계획

### 4.1 CSS 프레임워크
- **Tailwind CSS** (현재 사용 중)
- 반응형 클래스: `sm:`, `md:`, `lg:`
- 컨테이너: `container mx-auto px-4`

### 4.2 컴포넌트 패턴

```tsx
// 반응형 그리드 예시
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
  {items.map(item => <Card key={item.id} />)}
</div>

// 모바일 숨김/표시
<div className="hidden md:block">데스크탑 전용</div>
<div className="block md:hidden">모바일 전용</div>
```

### 4.3 새로운 컴포넌트 필요

| 컴포넌트 | 용도 |
|----------|------|
| `BottomSheet` | 모바일 모달 대체 |
| `BottomTabBar` | 모바일 하단 네비게이션 |
| `SwipeCarousel` | 알림 카드 스와이프 |
| `MobileNav` | 모바일 전용 네비게이션 |
| `PullToRefresh` | 당겨서 새로고침 |

### 4.4 성능 최적화

- 이미지: `next/image` 사용, 모바일용 작은 사이즈
- 코드 스플리팅: 페이지별 번들
- 폰트: 서브셋 + `font-display: swap`
