## 🎯 Phase 1: 공통 FileUpload 컴포넌트 작성

### Task 1-1: 기본 FileUpload 컴포넌트 구조 생성
**목표**: 최소 기능 버전(MVP) 컴포넌트 생성

**체크리스트**:
- [ ] `components/ui/file-upload.tsx` 파일 생성
- [ ] Props 인터페이스 정의
- [ ] 기본 UI 구조 작성 (레이블 + 업로드 영역)
- [ ] hidden input 연결
- [ ] 파일 선택 시 onChange 콜백 호출

**테스트**:

2. 파일 선택 시 onChange가 호출되는가?
3. label prop이 정상 표시되는가?

### Task 1-2: 계층 구조 및 스타일 적용
**목표**: 3단계 계층 구조 적용

**체크리스트**:
- [ ] Level 1: 타이틀 + 필수 배지
- [ ] Level 2: 업로드 영역 (강조 배경 + 테두리)
- [ ] Level 3: 도움말 텍스트 (선택)
- [ ] description prop 추가
- [ ] required prop 추가

**테스트**:
1. 필수 배지가 required=true일 때만 표시되는가?
2. description이 있을 때만 표시되는가?
3. 계층이 시각적으로 명확한가?

**완료 조건**:
- 디자인 시스템의 색상/타이포그래피 규칙 준수
- 3단계 계층이 명확히 구분됨

### Task 1-3: 호버 및 상태 스타일

**체크리스트**:

- [ ] 호버 시 테두리 강조
- [ ] disabled 상태 스타일
- [ ] uploading 상태 스타일 (로딩 표시)
- [ ] 포커스 상태 (접근성)

**테스트**:
1. 마우스 호버 시 스타일이 변경되는가?
2. disabled=true일 때 클릭이 막히는가?
3. uploading=true일 때 로딩 표시가 나타나는가?

**완료 조건**:
- 모든 상태에서 명확한 시각적 피드백 제공

### Task 1-4: 파일 형식 및 크기 검증
**목표**: 클라이언트 측 파일 검증

**체크리스트**:
- [ ] accept prop 기반 형식 검증
- [ ] maxSize prop 기반 크기 검증
- [ ] error prop 추가
- [ ] 에러 메시지 표시 UI

**테스트**:

2. 크기 초과 파일 선택 시 에러 표시되는가?
3. 정상 파일만 onChange에 전달되는가?
4. 에러 메시지가 명확한가?

**완료 조건**:
- 모든 검증 시나리오에서 명확한 에러 메시지 표시

### Task 1-5: 드래그 앤 드롭 지원
**목표**: 파일 드롭 기능 추가

**체크리스트**:
- [ ] onDragOver, onDragLeave, onDrop 이벤트 핸들러
- [ ] 드래그 오버 시 시각적 피드백 (배경색 변경)
- [ ] 드롭 시 파일 검증 및 onChange 호출
- [ ] 다중 파일 드롭 방지 (첫 번째 파일만 선택)

**테스트**:
1. 파일을 영역에 드래그 시 배경색이 변경되는가?
2. 파일을 드롭하면 onChange가 호출되는가?
3. 검증 로직이 드롭 시에도 작동하는가?
4. 드래그를 벗어나면 원래 스타일로 돌아가는가?

**완료 조건**:
- 드래그 앤 드롭으로 파일 선택 가능

**완료 조건**:
