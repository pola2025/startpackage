# PRD: 홈페이지 제작요청에서 아임웹 옵션 삭제

## 개요
홈페이지 제작요청 페이지에서 "아임웹 제작" 옵션을 삭제하고, 외부 서비스 제작만 남깁니다.
아임웹 가이드 문서는 기존 사용자를 위해 유지합니다.

## 작업 범위

### 1. 수정 대상 파일
| 파일 | 작업 내용 |
|------|----------|
| `app/dashboard/homepage/page.tsx` | 아임웹 옵션 UI 삭제 |
| `lib/schemas/submission.schema.ts` | **유지** (기존 데이터 보존) |
| `prisma/schema.prisma` | **유지** (기존 데이터 보존) |
| `docs/guides/Guide_imweb.txt` | **유지** (가이드 문서 유지) |

### 2. 유지 대상 (삭제하지 않음)
- **DB 스키마의 아임웹 관련 필드**: 기존 사용자 데이터 보존
- **아임웹 가이드 문서**: `docs/guides/Guide_imweb.txt`
- **기존 사용자의 아임웹 입력값**: 데이터베이스에 저장된 값

## 상세 작업 내용

### 1. `app/dashboard/homepage/page.tsx` 수정

#### 삭제할 내용:
1. **제작 방식 선택 카드에서 "아임웹" 옵션 삭제** (Line 305-346)
   - 라디오 버튼 및 설명 텍스트 삭제

2. **아임웹 입력 폼 전체 삭제** (Line 394-526)
   - 아임웹 계정 정보 카드 전체
   - 아임웹 ID/PW/관리자PW 입력 필드
   - 가입 안내, 진행 과정 안내 등

3. **관련 상태 변수 삭제**:
   - `imwebId`, `setImwebId`
   - `imwebPw`, `setImwebPw`
   - `imwebAdminPw`, `setImwebAdminPw`
   - `isImwebValid` 검증 로직

4. **저장 로직에서 아임웹 관련 처리 삭제**:
   - `handleSave()` 함수 내 `method === "아임웹"` 분기

5. **HomepageData 인터페이스에서 아임웹 필드 삭제**:
   - `아임웹ID`, `아임웹PW`, `아임웹관리자PW` 필드

#### 수정할 내용:
1. **"외부서비스"를 기본값으로 자동 선택**
   - 제작 방식 선택 UI 단순화 (선택 카드 제거 가능)
   - 또는 외부서비스만 남기고 단일 옵션으로 변경

2. **페이지 설명 텍스트 수정**
   - "제작 방식을 선택하고" → "필요한 정보를 입력해주세요"
