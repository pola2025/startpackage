# PRD: 스타트패키지 랜딩페이지 UI/UX 개선

## 1. 현재 상태 분석

### 1.1 페이지 구조
- Hero 섹션 → 패키지 구성 → 디자인 항목 → 홈페이지 스타일 → 마케팅 자동화 → Footer

### 1.2 발견된 문제점

| 영역 | 문제점 | 심각도 |
|------|--------|--------|
| Hero | 타이틀 색상이 너무 연해서 거의 안 보임 | Critical |
| Hero | CTA가 하나뿐이고 단조로움, 시각적 요소 부재 | High |
| 패키지 구성 | 3개 카드가 동일한 무게감, 차별화 없음 | High |
| 패키지 구성 | 가격 정보 부재 | High |
| 전체 | 신뢰 요소 부재 (실적, 프로세스, 보증) | Critical |
| 전체 | 문의/신청 CTA 부재 | Critical |
| Footer | 너무 단순함, 연락처 정보 없음 | Medium |

---

## 2. 개선 목표

### 2.1 핵심 목표
1. **전환율 향상**: 명확한 CTA와 가격 정보 제공
2. **신뢰도 구축**: 전문성과 실적을 보여주는 요소 추가
3. **정보 전달력**: 패키지 가치를 명확하게 전달

### 2.2 타겟 사용자
- 새로 사업을 시작하는 창업자
- 브랜딩이 필요한 소규모 사업자
- 세무사, 노무사, 법무사 등 전문직

---

## 3. 개선 사항

### 3.1 Hero 섹션

**현재 문제:**
- 타이틀 "스타트패키지"가 text-white/40 정도로 거의 안 보임
- 단일 CTA 버튼만 존재
- 시각적 임팩트 부족

**개선 방향:**
```
[AS-IS] 희미한 타이틀 + 단일 버튼
[TO-BE] 명확한 타이틀 + 가격 배지 + 듀얼 CTA + 핵심 혜택 요약
```

**구체적 변경:**
1. 타이틀 색상: `text-white` (100% 불투명)
2. 가격 정보 배지 추가: "150만원 상당 → 99만원"
3. 듀얼 CTA: "패키지 구성 보기" + "무료 상담 신청"
4. 핵심 혜택 3가지 아이콘 배치

---

### 3.2 패키지 구성 섹션

**현재 문제:**
- 3개 카드가 동등한 무게감
- 가격 정보 없음
- 차별화 요소 부족

**개선 방향:**
1. 각 카드에 예상 가격/가치 표시
2. 카드별 핵심 강조점 추가
3. 전체 패키지 가격 표시

---

### 3.3 신뢰 요소 섹션 (신규)

**추가할 요소:**
1. **실적 숫자**: "누적 200+ 고객사", "평균 3일 제작"
2. **프로세스 안내**: 계약 → 디자인 → 제작 → 납품 (4단계)
3. **보증 요소**: "100% 만족 보장", "무료 수정 2회"

---

### 3.4 CTA 섹션 (신규)

**위치:** 페이지 하단 (Footer 바로 위)

**구성:**
- 강력한 헤드라인: "지금 시작하세요"
- 가격 정보: "패키지 전체 99만원 (VAT 별도)"
- CTA 버튼: "무료 상담 신청"
- 연락처 정보: 전화번호, 이메일

---

### 3.5 Footer 개선

**추가할 정보:**
- 회사 정보 (상호, 대표, 사업자번호)
- 연락처 (전화, 이메일)
- 운영 시간

## 5. 디자인 가이드라인

### 5.1 색상 팔레트 (관공서 스타일)
- **Primary**: slate-800 (메인 배경)
- **Secondary**: slate-600 (보조 요소)
- **Accent**: blue-600 (CTA, 강조)
- **Success**: emerald-600 (긍정 요소)
- **Text**: gray-900 (본문), white (다크 배경)

### 5.2 타이포그래피
- 헤드라인: text-4xl ~ text-6xl, font-bold
- 서브헤드: text-xl ~ text-2xl, font-semibold
- 본문: text-base ~ text-lg

### 5.3 컴포넌트 스타일
- 카드: rounded-2xl, shadow-sm, border
- 버튼: rounded-xl, font-semibold
- 아이콘: Lucide 단색 아이콘만 사용
