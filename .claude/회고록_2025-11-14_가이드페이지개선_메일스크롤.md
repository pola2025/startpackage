### 1️⃣ 가이드 페이지 URL 해시 탭 네비게이션

**문제점**:
- 가이드 페이지의 각 탭을 직접 링크로 공유할 수 없음
- 사용자에게 특정 탭을 안내할 때 "아임웹 탭을 눌러주세요"라고 설명해야 함

**해결 방법**:
```tsx
// URL 해시에서 탭 읽기
useEffect(() => {
  const hash = window.location.hash.slice(1);
  if (hash) {
    setActiveTab(hash);
  }
}, []);

// 탭 변경 시 URL 해시 업데이트
const handleTabChange = (value: string) => {
  setActiveTab(value);
  window.history.pushState(null, "", `#${value}`);
};
```

**결과**:
- `/dashboard/guides#telegram` → 텔레그램 탭
- `/dashboard/guides#imweb` → 아임웹 탭
- `/dashboard/guides#design` → 인쇄물 발주 탭
- 링크 공유 가능, 브라우저 뒤로가기/앞으로가기 지원

**파일**: `app/dashboard/guides/page.tsx:10-24`

### 2️⃣ 아임웹 요금 체계 상세화

**문제점**:
- 기존: 단순히 "월 22,000원"만 표시
- 장기 결제 시 월 환산 금액을 계산해야 함
- 도메인 + 호스팅 비용 포함 여부 불명확

**해결 방법**:
1. **요금 테이블 추가**:
   - 결제 기간별 총 금액
   - 월 환산 금액 (비교 편리)
   - 할인율 명시

2. **계산 결과**:
   | 기간 | 총 금액 | 월 환산 | 할인율 |
   |------|---------|---------|--------|
   | 1개월 | 22,000원 | 월 22,000원 | - |
   | 3개월 | 62,700원 | 월 20,900원 | 5% |
   | 6개월 | 118,800원 | 월 19,800원 | 10% |
   | 12개월 | 211,200원 | 월 17,600원 | 20% |

3. **도메인 + 호스팅 포함 안내**:
   ```tsx
   <div className="bg-indigo-50 border-2 border-indigo-200 rounded-lg p-3 mb-3">
     <p className="text-sm text-indigo-900 font-medium">
       💡 <strong>도메인 + 호스팅 비용이 포함된 금액</strong>입니다
     </p>
   </div>
   ```

**파일**: `app/dashboard/guides/page.tsx:258-308`

### 4️⃣ 홈페이지 완료 자동문자 발송 기획서

**배경**:
- 홈페이지 제작 완료 시 고객에게 안내 필요
- 아임웹 요금 정보 전달
- 계정 이관 절차 안내

**기획 내용**:

1. **트리거**: 관리자가 "홈페이지 완료" 상태로 변경 시 자동 발송

2. **문자 내용 (3가지 버전)**:
   - 버전 1: 기본형 (상세 안내)
   - 버전 2: 간략형 (비용 절감)
   - 버전 3: 알림톡 (카카오 비즈니스 연동 시)

3. **동적 변수**:
   - `{{고객명}}`, `{{홈페이지_URL}}`
   - `{{담당자_이름}}`, `{{담당자_연락처}}`

4. **DB 스키마**:
   ```typescript
   model Application {
     homepageUrl       String?
     homepageCompleted Boolean @default(false)
     completedAt       DateTime?
     smsNotified       Boolean @default(false)
     smsNotifiedAt     DateTime?
   }
   ```

5. **API 엔드포인트**:
   - `POST /api/applications/[id]/complete`
   - 요청: `{ homepageUrl: "https://..." }`
   - 응답: 완료 시각, SMS 발송 상태

**파일**: `.claude/homepage-completion-sms-spec.md`

### 5️⃣ 관리자 메일 발송 스크롤 기능

**문제점**:
- 긴 메일 내용 입력 시 textarea가 고정 높이
- 내용이 많으면 스크롤 불가능

**해결 방법**:
```tsx
// 기존
className="... resize-none"

// 변경 후
className="... resize-none overflow-y-auto max-h-[400px]"
```

**적용 위치**:
1. 메시지 발송 다이얼로그 (SMS/이메일)
2. 문의하기 메시지 다이얼로그

**동작**:
- 기본 8줄 표시
- 8줄 초과 시 자동 스크롤
- 최대 높이 400px (약 20줄)

**파일**: `app/admin/(dashboard)/users/user-actions.tsx:636, 753`
