// theme.extend.colors — 기존 navy 팔레트 재사용 // Gold 팔레트 제거, 시맨틱 토큰만 추가 semantic: { success: { 50:'#e8edf2', 100:'#c5cfd9', 500:'#1b2838', 600:'#0d1b2a' }, design: { 50:'#e8edf2', 100:'#9fafc0', 500:'#2d4d6b', 600:'#1f3044' }, warning: { 50:'#e8edf2', 100:'#c5cfd9', 500:'#5a7893', 600:'#3b6080' }, social: { 50:'#e8edf2', 100:'#c5cfd9', 500:'#7990a7', 600:'#5a7893' }, inactive: { 50:'#e8edf2', 100:'#c5cfd9', 500:'#9fafc0', 600:'#7990a7' }, }, error: { 50:'#faefed', 100:'#ecd0cc', 500:'#b85e52', 600:'#8b3f35' }, // 기존 navy 팔레트는 그대로 유지 (UI 기본 색상) // gold 팔레트 삭제 → navy로 대체

pink SNS/인스타 → social 300/400
gray 비활성/종료 → inactive 200/100
red 에러/긴급 → error terra

설계 근거

명도 = 진행도: 어두울수록 확정(900), 밝을수록 대기(200). 직관적 위계.
단일 팔레트: Navy 50~900 하나로 5개 역할 구분. 색상 수 1/6 감소.
Red 분리: 전체 시스템에서 유일한 난색(Warm). Navy 속에서 즉시 시선 확보.
Gold 제거 이유: Gold+Navy 2색 체계에서 시맨틱 role까지 Gold를 쓰면 "강조"와 "상태"가 혼재. Navy 단일 축으로 정리하면 UI 액센트와 시맨틱 역할이 분리됨.
접근성: Navy-900 on Navy-50 = 명암비 8.2:1 (WCAG AAA). Terra-600 on Terra-50 = 7.5:1 (AAA).
