이중 레이어 규칙 요약

Layer 1 — 배경 (Navy 명도)
카드 bg, 보더, 도트 색상. 어두울수록 완료에 가깝고, 밝을수록 대기/비활성.
900(확정) → 800(발주) → 700(제작중) → 400(대기) → 200(종료)
유일한 예외: terra-50 배경 = 긴급(수정요청/시안확인)
Layer 2 — 폰트 (시맨틱 색상)
상태 텍스트와 이모지에만 적용. 사용자에게 "행동 신호"를 보냄.
녹색(ok-600) = 완료, 안심, 체크마크 → 추가 행동 불필요
붉은색(terra-500) = 필요, 대기, 주의, 긴급 → 사용자 행동 필요
네이비(navy-600) = 제작중, 진행 → 대기 중(중립)
연한 네이비(navy-300) = 종료, 비활성 → 무시 가능
핵심 원칙
• 카드 아이템명(로고, 명함 등)은 항상 navy-900 (종료 시 navy-300)
• 상태 텍스트(✓확정, ⚠대기)만 시맨틱 폰트 적용
• 배경과 폰트가 동시에 강조되는 건 긴급(수정요청)뿐 → 이중 강조로 최고 주의 환기
