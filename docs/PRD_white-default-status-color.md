# PRD: 흰색 기본 + 상태별 색상 전면 적용

## 개요

모든 UI 박스/카드의 기본 배경을 **흰색**으로 통일하고, **상태가 있을 때만** 배경색을 부여한다.
장식용 그라데이션, 항목별 다른 색상 아이콘, 과도한 테두리를 제거하여 깔끔한 UI를 구현한다.

## 핵심 원칙

```
┌─────────────────────────────────────────────────────────┐
│  1. 박스 배경 = 흰색 (기본값)                            │
│  2. 배경색 = 상태가 있을 때만 (확인필요/완료/경고 등)      │
│  3. 상태 표현 = 텍스트 색상 + 도트/뱃지 (배경은 보조)      │
│  4. 그라데이션 = 전면 제거 (인증 페이지 포함)              │
│  5. border-2 → border (전역)                            │
└─────────────────────────────────────────────────────────┘
```

## 상태 색상 체계

| 상태 분류        | 배경          | 텍스트           | 도트/뱃지      | 용도               |
| ---------------- | ------------- | ---------------- | -------------- | ------------------ |
| 기본/중립        | `bg-white`    | `text-navy-900`  | `bg-navy-700`  | 제작중, 일반       |
| 확인필요 (terra) | `bg-terra-50` | `text-terra-600` | `bg-terra-500` | 시안확인, 발주요청 |
| 완료 (ok)        | `bg-white`    | `text-ok-600`    | —              | 발주완료, 제작완료 |
| 경고 (amber)     | `bg-white`    | `text-amber-600` | —              | 배송중, 마감임박   |
| 대기             | `bg-white`    | `text-navy-300`  | `bg-navy-200`  | 대기중, 미시작     |
| 에러             | `bg-red-50`   | `text-red-700`   | —              | 폼 검증 실패       |

> **확인필요(terra)만 배경색 부여** — 사용자 액션이 필요한 상태를 시각적으로 강조

## CRITICAL BUG: terra/ok 색상 미정의
