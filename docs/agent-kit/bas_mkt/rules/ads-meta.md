# Meta 잠재 고객 광고 규칙 (인스턴트 양식)

우리 회사(`brand.json`의 `company`) 광고 계정에 상담 신청을 받는 광고를 만드는 규칙입니다. 작업 순서는 `AGENTS.md` §8을 따릅니다. 아래 표준은 폴라애드가 운영하는 광고 설정과 같으며, 2026-10-17에 Marketing API 검증(`validate_only`)을 통과했습니다.

---

## 1. 표준 광고 설정

| 항목 | 표준 | 비고 |
| --- | --- | --- |
| 이름 | `YYMMDD_소재·목표명` (예: `261017_정책자금광고`) | 캠페인 · 광고 세트 · 광고 · 입력양식 이름을 모두 같게 합니다. 빈칸 없이 씁니다. |
| 목표 | 잠재 고객 | 구매 유형 경매, 특별 광고 카테고리 없음 |
| 예산 | 캠페인 하루 예산, 입찰 전략 최고 볼륨 | 교육 기준은 하루 28,000원(달러 계정은 20달러)입니다. 사람이 말한 금액을 그대로 씁니다. |
| 전환 위치 | 인스턴트 양식, 우리 페이스북 페이지 | 성과 목표는 잠재 고객 수 극대화 |
| 위치 | 대한민국, 제주 제외 | 특정 지역은 §5 |
| 언어 | 한국어 | API 값 `12`(23은 스페인어) |
| 연령 | 25세 이상 | Advantage+ 타겟 확장은 끕니다. |
| 노출 위치 | 인스타그램만: 피드 · 탐색 · 릴스 · 프로필 피드, 모바일 | 페이스북 · Audience Network · 메신저 · 쓰레드는 넣지 않습니다. "노출 위치가 아닌 곳에도 노출"은 끕니다. |
| 광고 | 단일 이미지, 행동 유도 버튼 **신청하기** | "다른 광고와 함께 게시"(여러 광고주의 광고)는 끕니다. |
| 상태 | 모두 일시 중지로 만듦 | 사람이 "게재 시작"이라고 답한 뒤에만 켭니다. 켜기 전에는 광고비가 나가지 않습니다. |

`ads.mjs`가 이 값으로 만들고, 만든 뒤 Meta에서 다시 읽어 표준과 한 줄씩 대조합니다. 하나라도 다르면 게재를 시작하지 않습니다.

## 2. 입력양식

사람이 보낸 요청 문장에 질문·정보 취급 설명·완료 화면 문구가 있으면 그 문구를 고치거나 다듬지 않고 그대로 씁니다(`ad.json`의 `form`). 문장에 없으면 아래 표준을 씁니다. 사람에게 양식을 다시 확인받지 않습니다. 만든 뒤 Meta에서 다시 읽어 `ad.json`과 대조합니다.

| 순서 | 질문 | 형식 |
| --- | --- | --- |
| 1 | 사업자 종류 | 선다형: 개인사업자 / 법인사업자 |
| 2 | 지역 (예: 서울 강남구) | 직접 입력 |
| 3 | 업종 / 회사명 | 직접 입력(한 칸) |
| 4 | 직전년도 매출 | 직접 입력 |
| 5 | 이름 | Facebook·Instagram 정보로 자동 입력 |
| 6 | 전화번호 | Facebook·Instagram 정보로 자동 입력 |

- 양식 언어는 한국어이고 양식 유형은 "더 많은 제출 수"입니다. 광고 대상이 아닌 사람에게는 양식을 보여 주지 않습니다.
- 개인정보처리방침: 회사 홈페이지 주소 뒤에 `/privacy`를 붙인 주소가 기본입니다. 요청 문장에 다른 주소가 있으면 `privacy_url`에 씁니다. 링크 문구는 "<회사명> 개인정보처리방침"입니다.
- 정보 취급 설명: 제목 "개인정보 수집·이용 안내", 표준 내용 "접수된 정보는 상담 후 폐기됩니다."
- 완료 화면: 표준 제목 "상담접수 완료", 표준 내용 "담당자 확인후 1일 이내 연락드릴 예정입니다.", 버튼 "웹사이트 보기"(회사 홈페이지)
- 이름·전화번호 자동 입력은 빼지 않습니다. 상담 연락을 받을 수 없게 됩니다.
- **양식은 만든 뒤 고칠 수 없습니다.** 바꾸려면 새 이름으로 새 양식을 만들고 새 광고에 연결합니다. 그래서 요청 문장의 문구를 글자 그대로 옮깁니다.

## 3. 광고폴더와 `ad.json`

광고폴더는 `C:\bas_mkt\ads\<YYYYMMDD>-<영문-이름>`입니다(예: `C:\bas_mkt\ads\20261017-policy-fund`).

```json
{
  "name": "261017_정책자금광고",
  "daily_budget": 28000,
  "image": "ad.png",
  "headline": "정책자금 상담 신청",
  "message": "📌 정책자금 신청,\n어디서부터 시작할지\n막막하신가요?\n\n✅ 우리 회사가 받을 수 있는\n자금부터 확인해 드립니다.\n\n👇 아래 신청하기를 눌러\n상담을 신청하세요.",
  "region": null,
  "form": {
    "questions": [
      { "label": "사업자 종류", "options": ["개인사업자", "법인사업자"] },
      { "label": "지역 (예: 서울 강남구)" },
      { "label": "업종 / 회사명" },
      { "label": "직전년도 매출" },
      { "auto": "이름" },
      { "auto": "전화번호" }
    ],
    "disclaimer": "접수된 정보는 상담 후 폐기됩니다.",
    "done_title": "상담접수 완료",
    "done_body": "담당자 확인후 1일 이내 연락드릴 예정입니다."
  }
}
```

- `form`: 요청 문장의 질문을 순서대로 `questions`에 넣습니다. 선택지가 있으면 `options`, 직접 입력이면 `label`만 씁니다. 자동 입력은 `{ "auto": "이름" }`, `{ "auto": "전화번호" }`, `{ "auto": "이메일" }`만 됩니다. 문장에 질문이 없으면 `form`을 빼서 표준 양식을 씁니다.
- `privacy_url`: 요청 문장에 개인정보처리방침 주소가 있을 때만 넣습니다.
- `daily_budget`은 광고 계정 통화 단위의 숫자입니다(원화 계정 `28000`, 달러 계정 `20`). 통화는 `node ads.mjs check` 출력에 나옵니다.
- 개인정보처리방침 주소는 `form --check`가 열리는지 확인합니다. 열리지 않으면 그때만 사람에게 실제 주소를 묻습니다.
- 만든 광고의 id는 `state.json`에 남습니다. 지우거나 고치지 않습니다. 중간에 멈춰도 같은 명령을 다시 실행하면 만든 것은 건너뛰고 이어서 합니다.

## 4. 광고 이미지와 문구

**이미지**
- 크기는 **1080×1350(4:5)** 또는 1080×1080입니다. 인스타그램 피드 광고는 4:5까지 세로로 보여 줍니다.
- 블로그 글이 있으면 `cd C:\bas_mkt\tools\blog` 후 `node cards.mjs <글폴더> --ad <광고폴더>`로 블로그 표지를 4:5로 다시 그립니다. 표지 문구를 새로 쓰지 않습니다.
- 사람이 이미지를 주면 광고폴더에 복사한 뒤 크기를 확인합니다. 크기가 다르면 늘리거나 자르지 않고, 1080×1350으로 다시 만들어 달라고 알립니다.

**문구**
- `message`(본문)는 인스타 캡션처럼 모바일 폭으로 줄을 바꿉니다(`sns-meta.md` §5). 3~6줄 안팎으로 짧게 쓰고, 첫 줄에 누구에게 무엇을 주는지 씁니다.
- 본문 마지막 줄은 "👇 아래 신청하기를 눌러 …"로 버튼을 안내합니다. 버튼 이름이 "신청하기"이기 때문입니다.
- `headline`(제목)은 40자 안쪽으로 씁니다.
- 숫자·사업명은 블로그 글의 `facts.json`이나 사람이 준 값만 씁니다.
- 쓰지 않는 표현(광고 검토에서 거부되거나 신고 대상이 됩니다)
  - 승인·결과 약속: "무조건", "100%", "보장", "즉시 승인", "승인 확정"
  - 개인 특성 지목: "신용불량이신가요?", "대출 거절당하셨나요?"처럼 보는 사람의 신용·재정 상태를 짚는 문장
  - 기관 사칭: 정부 기관 로고, "정부지원센터"처럼 공공기관으로 오인되는 이름, 공고를 낸 기관이 직접 하는 광고처럼 보이는 문장

## 5. 특정 지역 광고

- 사람이 지역을 말할 때만 씁니다. 먼저 "지역만 공략하면 전국 광고보다 결과 하나당 단가가 3~4배 오를 수 있습니다"라고 알립니다.
- 지역 이름을 하나씩 넣지 않습니다. 목표 지역 전체를 덮는 **중심 좌표 하나 + 반경 10km 이상**(중심에서 가장 먼 곳까지 거리 + 1~2km)으로 잡습니다. 예: 창원시 전체 → 창원시청 좌표, 반경 15km.
- `ad.json`의 `region`에 `{ "name": "창원시", "lat": 35.2281, "lng": 128.6811, "radius_km": 15 }`처럼 씁니다. 반경은 10~80km입니다. 지역 광고에는 제주 제외를 붙이지 않습니다.

## 6. 하지 않는 일

- 사람이 "게재 시작"이라고 답하기 전에 광고를 켜지 않습니다.
- 표준과 다른 값(예산 단위, 노출 위치, 연령, 언어)을 임의로 넣지 않습니다. 사람이 다른 값을 직접 요청하면 그대로 하되, 표준과 무엇이 다른지 한 줄로 알립니다.
- 게재 중인 광고를 고치지 않습니다. 바꿀 것이 있으면 끄고(`pause`) 새 이름으로 새 광고를 만듭니다. 광고를 삭제하지 않습니다.
- 접수된 고객 정보(리드)를 내려받거나 다른 곳으로 보내지 않습니다. 접수는 폴라애드가 연결한 홈페이지 관리자 대시보드의 상담신청과 텔레그램으로 사람이 받습니다. Meta의 잠재 고객 센터(`https://business.facebook.com/latest/leads_center`)에서도 볼 수 있습니다.
