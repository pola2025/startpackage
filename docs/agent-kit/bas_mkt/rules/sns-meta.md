# Meta SNS 게시 규칙 (인스타그램 · 페이스북 페이지 · 쓰레드)

우리 회사(`brand.json`의 `company`) 계정에 콘텐츠를 올리는 규칙입니다. 작업 순서는 `AGENTS.md` §7을 따릅니다.

---

## 1. 채널과 게시 방식

| 채널 | 게시 방식 | 도구 |
| --- | --- | --- |
| 인스타그램 + 페이스북 페이지 | 같은 콘텐츠를 동시에 올립니다. 사람이 "게시"라고 답하면 바로 올립니다. | `tools\meta\publish.mjs` |
| 쓰레드 | 대표자가 정한 컨셉으로 그날 올릴 4편을 그날 설정하고, PC가 켜져 있는 동안 08:00 · 11:30 · 15:00 · 18:30(3시간 30분 간격)에 한 개씩 올립니다. | `tools\meta\threads.mjs` + 시각별 실행 작업 |

인스타그램·쓰레드 API에는 예약 게시 기능이 없고, PC가 켜져 있어야 올라갑니다. 그래서 세 채널 모두 **그날 올릴 것만 그날 설정**합니다. 다른 날짜 예약이나 미리 써 둔 글을 나눠 올리는 방식은 다루지 않습니다(폴라애드 고급과정 개별교육). 네이버 블로그는 예약 발행이 되므로 이 제한과 관계없습니다.

---

## 2. 인스타그램 카드뉴스

- 크기는 **1080×1440(3:4)**입니다. 인스타그램 프로필 그리드가 3:4로 바뀌어서, 이 크기면 그리드에서 잘리지 않습니다.
- 첫 장(표지)은 **대형 타이포**로 핵심 메시지를 크게 씁니다. 검색 결과와 프로필 그리드에는 첫 장만 보이므로, 첫 장만 봐도 무슨 내용인지 알 수 있어야 합니다.
- 장수는 표지 + 메시지 카드 + 회사 카드로 6장 안팎이 기본입니다(캐러셀은 2~10장).
- 블로그 글로 만들 때는 `node ..\blog\cards.mjs <글폴더>`를 씁니다. 블로그의 표지·메시지 카드 문구를 그대로 3:4로 다시 그립니다. 카드 문구를 새로 쓰지 않습니다.
- 카드 속 숫자·사업명은 블로그 글의 `facts.json`에 있는 값만 씁니다.

## 3. 릴스(세로 영상)

- 크기는 **9:16, 1080×1920**입니다. 3초 이상, 90초 안쪽을 권장합니다. MP4 파일이어야 합니다.
- 화면 위 270px, 아래 670px, 좌우 65px에는 인스타그램 버튼과 캡션이 겹칩니다. 글자는 그 안쪽(가로 65~1015, 세로 270~1250)에 둡니다.

## 4. 사람이 미리 만든 콘텐츠

- 사람이 이미지·영상을 주면 먼저 `node size.mjs <파일 또는 폴더>`로 크기를 점검합니다.
- ❌가 나온 파일은 올리지 않습니다. 어떤 크기로 다시 만들어야 하는지(카드 1080×1440, 영상 1080×1920) 사람에게 알리고 기다립니다. 에이전트가 늘리거나 잘라서 비율을 바꾸지 않습니다.
- ⚠가 나온 이미지(예: 1080×1350)는 올릴 수 있지만, 프로필 그리드에서 좌우가 조금 잘린다고 알려 줍니다.

## 5. 인스타그램 캡션 (모바일 가로폭)

인스타그램은 캡션을 좁은 모바일 폭으로 보여 줍니다. 긴 줄은 아무 데서나 꺾여서 읽기 어렵습니다. 그래서 줄바꿈을 미리 넣어 올립니다.

1. **한 줄은 14~20자(한글 기준)**로 씁니다. 어절·구 경계에서 의미 단위로 줄을 바꿉니다. 단어 중간에서 끊지 않습니다. 쉼표·마침표가 있으면 그 뒤에서 먼저 끊습니다.
2. **문장 덩어리가 아니라 문단으로** 씁니다. 생각 하나가 끝나면 빈 줄 하나를 둡니다. 한 문단은 2~4줄이 적당합니다. 빈 줄은 한 줄만 둡니다.
3. **이모지를 적극적으로** 씁니다. 문단 첫머리와 핵심 줄에 내용에 맞는 이모지를 넣습니다(📌 핵심, 💰 금액, 📅 기간, ✅ 조건, 📝 준비 서류, 📞 문의 등).
4. 순서는 제목 줄 → 핵심 내용 → 조건·기간 → 마무리 → 해시태그입니다.
5. **해시태그는 마지막 문단에 한 줄로** 모읍니다. 3~5개를 권장합니다. 해시태그 줄은 줄바꿈하지 않습니다.
6. 캡션의 링크는 눌리지 않으므로 넣지 않습니다. 블로그 글로 만든 카드뉴스라면 "신청 방법은 블로그에 정리했습니다"처럼 씁니다.
7. 숫자·사업명은 원문 값만 씁니다. "보장", "무조건", "100% 승인" 같은 표현을 쓰지 않습니다.

`publish.mjs --check`가 22자를 넘는 줄, 7줄 이상 이어진 문단, 이모지가 없는 문단을 경고합니다. 경고가 나오면 고친 뒤 넘어갑니다.

예시:

```
📌 창원시 중소기업 육성자금
이차보전 연 2.5% 지원

💰 경영안정자금 2,100억 원
이자 일부를 창원시가
대신 부담하는 방식입니다.

✅ 접수는 자금이 소진될
때까지 받습니다.

📝 신청 방법과 준비 서류는
블로그에 정리했습니다.

#정책자금 #창원시 #중소기업육성자금 #이차보전
```

## 6. 쓰레드

### 6.1 컨셉

대표자가 말한 컨셉을 `C:\bas_mkt\threads-concept.md`에 정리하고, 모든 글을 그 컨셉에 맞춰 씁니다. 대표자가 따로 말하지 않은 부분은 아래 기본값을 따릅니다.

- **독자**: 중소기업·소상공인 대표와 재무·경영 담당자
- **말투**: 존댓말. 문장 끝을 "~합니다", "~입니다", "~세요"로 끝냅니다.
- **내용**: 업종별 상황과 판단에 도움이 되는 정보(신청 시기, 준비 서류, 자주 틀리는 조건, 올해 바뀐 점). 정보 전달형이 가장 무난합니다.
- **넣지 않는 것**: 상담 권유("궁금하면", "상담 신청", "무료 상담", "DM"), 회사명, 링크·주소, 과장 표현("해드립니다", "100%", "무조건", "보장")

### 6.2 글 구조

- 한 편은 **첫 글 1개 + 추가 글 0~2개**입니다. 추가 글은 첫 글에 답글로 붙습니다.
- 한 편 전체는 200~500자, 첫 글과 추가 글은 각각 50~250자를 권장합니다. 한 글은 500자를 넘을 수 없습니다.
- **첫 글에는 이미지·링크를 넣지 않습니다.** 첫 글에 이미지나 링크가 있으면 검색과 노출에 불리합니다. 링크가 꼭 필요하면 추가 글에 둡니다(기본은 링크 없음).
- 주제 태그(`topic`)는 한 편에 하나입니다(예: "정책자금"). 50자 이하이고 마침표와 &를 쓰지 않습니다.

### 6.3 운영

- 그날 올릴 4개를 그날 준비해 `threads.mjs add`로 대기열에 넣습니다. 그날 못 올린 글(그 시각에 PC가 꺼져 있던 경우)은 다음 날 자동으로 빠지고 올라가지 않습니다.
- 오늘 올릴 글을 모두 올리면 같은 글을 반복하지 않고 게시를 멈춥니다.
- **자동 답글, 자동 좋아요·팔로우, 같은 문장 반복처럼 티 나는 활동은 하지 않습니다.** 게시 횟수는 늘릴 수 있지만, 늘릴 때도 정보 전달형 글만 올립니다.

예시(한 편):

```json
{
  "parts": [
    "정책자금은 공고가 나오면 바로 신청할 수 있는 것처럼 보이지만, 실제로는 서류 준비에 2~3주가 걸립니다.\n\n특히 부가가치세 과세표준증명원과 납세증명서는 발급 기준일이 공고마다 다릅니다.",
    "신청 직전에 서류를 떼면 기준일이 맞지 않아 다시 발급받는 경우가 많습니다.\n\n공고문의 '제출 서류' 항목에서 발급 기준일부터 확인하시면 시간을 줄일 수 있습니다."
  ],
  "topic": "정책자금"
}
```
