01. Research & Design Analysis

Light-Base Design Principle

화이트/라이트그레이 배경은 정보 신뢰도와 가독성을 극대화. 관공서, 금융기관의 90%+ 가 밝은 배경을 채택. 핵심은 여백과 타이포그래피 계층.

Trust Signal

Color Accent Strategy

밝은 배경에서는 액센트 컬러의 비중이 5-10%로 제한되어야 시선 집중 효과 극대화. 네이비/블루/골드/그린 중 하나만 메인 액센트로 사용.

Minimal Focus

2026 Animation on Light BG

밝은 배경에서는 그림자 변화, 보더 컬러 전환, 부드러운 fade가 효과적. 과도한 모션은 오히려 산만함 유발. 마이크로인터랙션 위주.

Motion Design

Korean Gov / Finance

금감원, 국민은행, 하나은행 등 — 순백 배경 + 블루/네이비 헤더 + 카드형 콘텐츠. 공지사항/팝업존/빠른서비스 3-zone 구조 공통 패턴.

Trust Signal

Stripe / Linear (Light Mode)

Stripe의 라이트 모드: #f6f9fc 배경, 보라 그라데이션 히어로. Linear: 순백 + 얇은 보더 + 모노크롬 아이콘. 극도의 여백 활용.

Minimal Focus

Day1 Design Adaptation

Day1의 다크+골드 톤을 라이트에 적용: 아이보리 배경 + 다크 텍스트 + 골드 액센트. 그리드 구조와 uppercase 라벨은 그대로 유지.

Minimal Focus

Light Background Design Rule

밝은 배경의 고급감은 "정밀한 여백 + 미세한 그림자 + 제한된 컬러"에서 나옵니다. 배경이 밝을수록 테두리와 그림자의 미세한 차이가 계층을 만들고, 텍스트의 무게감(font-weight)이 시각적 앵커 역할을 합니다. 4개 스타일 모두 순백~아이보리 배경에 각기 다른 액센트 전략을 적용했습니다.

02. New Style Proposals

Style 07
Civic Blue
관공서 / 공공기관 / 법무법인

Wireframe

Color Palette

Key Features

  • 네이비 헤더 + 밝은 블루 히어로 배경
  • Trust Counter Bar: 설립연도/고객수/승인율 숫자 강조
  • Split Hero: 좌측 텍스트 + 우측 이미지
  • 공지사항 + 빠른링크 복합 레이아웃
  • 카드형 서비스 소개 (아이콘+제목+설명)
  • 모바일: 수직 스택 + 하단 고정 CTA

Animation Spec

Scroll Counter

Trust Bar 진입 시 0→타겟 카운트업. IntersectionObserver + requestAnimationFrame. duration: 1.5s, easeOutExpo. 다크 텍스트가 밝은 배경에서 강하게 대비.

Card Lift

서비스 카드 hover 시 translateY(-4px) + box-shadow 강화. 밝은 배경에서 그림자 변화가 입체감을 만듦.

Section Fade-In

각 섹션 opacity:0→1 + translateY(24px→0). stagger 100ms. 밝은 배경이라 translateY 폭을 작게 설정.

Reference
금융감독원 국민은행 대한법률구조공단 GOV.UK
Style 08
Finance Ivory
금융기관 / 투자사 / 자산관리

Wireframe

Color Palette

Key Features

  • 아이보리/크림 배경 + 골드 액센트 (Day1 톤 라이트 변환)
  • 가는 골드 라인 디바이더로 세련된 구분
  • 중앙 정렬 히어로 + 듀얼 CTA
  • 파트너 로고 Marquee (라이트 배경)
  • 이미지-텍스트 교차 2단 레이아웃
  • 골드 숫자 Stats 섹션 (3열)

Animation Spec

Gold Line Expand

골드 디바이더 라인이 width:0→100%로 확장. IntersectionObserver 트리거. duration: 0.8s, easeInOut. 섹션 전환의 우아한 시각 신호.

Logo Marquee

파트너 로고 무한 가로 스크롤. @keyframes marquee 30s linear infinite. hover 시 일시정지. 라이트 배경에서 로고가 선명하게 보임.

Stats Counter

골드 컬러 숫자 카운트업. font-variant-numeric: tabular-nums. 아이보리 배경 위 골드가 프리미엄 느낌을 극대화.

Reference
Goldman Sachs J.P. Morgan Day1 Design Vanguard

Warm Consulting
컨설팅 / 회계법인 / 경영지원

Wireframe

Color Palette

Key Features

  • 웜화이트/크림 배경 + 다크 브라운 텍스트
  • 라운드 CTA + 원형 아이콘 (부드러운 인상)

Animation Spec

Testimonial Carousel

고객 후기 CSS scroll-snap 기반 슬라이드. 5초 간격 자동 전환. dot indicator + touch swipe. 따옴표가 먼저 fade-in 후 텍스트 등장.

Icon Float

원형 아이콘 hover 시 translateY(-3px) + 그림자 확장. 밝은 크림 배경에서 미세한 lift가 정교하게 느껴짐.

Smooth Fade

모든 섹션 opacity + translateY 조합. 웜톤 배경이라 전환 속도를 0.6s로 느리게 설정해 안정감 연출.

Style 10
Clean Tech
IT / 스타트업 / 기술 컨설팅

Wireframe

Color Palette

Key Features

  • 순백 배경 + 바이올렛/인디고 그라데이션 포인트
  • Bento Grid 레이아웃 (비대칭 카드)
  • 글래스모피즘 네비게이션 (스크롤 시 블러)
  • Pill badge 히어로 서브타이틀
  • 아바타 스택 Social Proof
  • 미세한 배경 Glow (밝은 버전)

Animation Spec

Light Glow

히어로 배경에 연한 radial-gradient 오브. 마우스 추적 이동 (밝은 배경이라 opacity 6-8%로 제한). 모바일에서는 고정.

Bento Stagger

Bento 카드 스크롤 진입 시 순차 등장. scale(0.97)→1 + opacity. delay: 80ms * index. 밝은 배경에서 border가 자연스럽게 나타남.

Gradient CTA

CTA hover 시 background-position 이동으로 그라데이션 시프트. background-size: 200%. transition: 0.4s ease.

Reference
Linear (Light) Vercel (Light) Stripe (Light) Raycast

Implementation Notes

공통 기반: 모든 스타일은 밝은 배경(#fafafa~#fdfcfa)을 베이스로 하며, IntersectionObserver 스크롤 트리거를 공유합니다. 밝은 배경에서는 box-shadow와 border의 미세한 변화가 핵심이므로, 그림자 값을 정교하게 조정해야 합니다.

차별화 전략: 4개 스타일이 각각 다른 온도감(Cool Blue → Warm Ivory → Warm Gold → Cool Violet)을 가져, 업종별 타겟이 명확합니다.
