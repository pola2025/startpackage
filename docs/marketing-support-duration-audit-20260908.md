# 마케팅 지원 기간 8주 통일

확인일: 2026-09-08 KST. 로컬 구현·검증 결과이며 운영 배포 완료 기록이 아니다.

## 반영 결과

- 모든 기수의 기본 마케팅 지원 기간을 8주로 통일했다. 기수명에 따른 과거 기간 분기는 제거했다.
- 고객 대시보드, 연장 신청창, 유료 상품, Meta 광고 안내, 홈페이지 옵션 안내, 관리자 기수·연장·광고 자동화 화면에 반영했다.
- 신규 연장 신청은 기존 종료일에서 56일을 더한다. Prisma와 D1 모두 같은 계산을 사용한다.
- 이미 저장된 고객별 종료일과 기존 신청의 날짜는 다시 쓰지 않았다.
- 유료 상품 총액 990,000원은 유지했다. 월 단가와 기간의 곱으로 설명하던 문구는 8주 총액으로 표시한다.
- 비교 안내, 과거 와이어프레임, 만료 안내 문서·메일 샘플과 수동 발송 스크립트의 해당 기간도 8주로 교체했다. 샘플별 기존 합계 금액은 유지했다.
- 별도 콘텐츠 대행의 월 단위 상품은 변경하지 않았다.

## 화면 삭제 판단

관련 화면은 실제 메뉴 또는 import로 연결되어 있다. 확인된 삭제 대상은 없다.
고객 연장 신청창은 대시보드에서 사용하며 유료 상품은 사이드바, 관리자 화면은 관리자 메뉴에서 접근한다.
로컬 HTML 시안은 요청 이력이 있는 검토 자료이므로 앱 메뉴에 없다는 이유로 삭제하지 않았다.
