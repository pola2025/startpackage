#### 제작물별 소요 일정 (영업일 기준)

**시안 제작 예정일**:
- 로고: 1~2일 (자료제출일 기준)

**인쇄물 제작 예정일** (발주 요청일 기준):
- 명함: 2~3일
- 명찰: 2~3일
- 대봉투: 4~5일
- 자문계약서 표지/내지: 7일

```typescript

  '자문계약서 표지': { min: 7, max: 7 },

};
```

### 2. 발주 요청 API에 예상도착일 계산 추가

**파일**: `app/api/workflows/[id]/order/route.ts`

**변경사항**:
- 발주 요청 시 `calculateExpectedArrival()` 함수로 예상도착일 자동 계산
- Workflow의 `예상도착일` 필드에 저장
- 제작물 타입에 따라 영업일 기준으로 계산

```typescript
// 발주 요청일 기준으로 예상 도착일 계산
const orderDate = new Date();
const expectedArrival = calculateExpectedArrival(orderDate, workflow.type);

const updated = await prisma.workflow.update({
  where: { id: workflowId },
  data: {
    status: "발주요청",
    발주요청일: orderDate,
    예상도착일: expectedArrival || null,
  },
});
```

### 4. 홈페이지 시안 확정 기능 추가

**파일**:
- `app/dashboard/workflows/page.tsx`
- `app/api/workflows/[id]/approve/route.ts`

**변경사항**:
- 홈페이지 워크플로우에 "시안 확정" 버튼 추가
- 로고와 홈페이지 모두 "시안 확정" 버튼으로 통일
- 인쇄물은 기존대로 "발주 요청" 버튼 유지

**approve API 수정**:
```typescript
// 로고와 홈페이지만 승인 가능
if (workflow.type !== "로고" && workflow.type !== "홈페이지") {
  return NextResponse.json({ error: "로고와 홈페이지만 확정할 수 있습니다." }, { status: 400 });
}

// 상태 확인
if (workflow.type === "로고" && workflow.status !== "시안컨펌요청") {
  return NextResponse.json({ error: "시안컨펌요청 상태에서만 확정할 수 있습니다." }, { status: 400 });
}

if (workflow.type === "홈페이지" && workflow.status !== "제작 완료") {
  return NextResponse.json({ error: "제작 완료 상태에서만 확정할 수 있습니다." }, { status: 400 });
}
```

**UI 변경**:
```typescript
{/* 로고와 홈페이지: 시안 확정 버튼 */}
```

## 🐛 해결한 문제

### 1. TypeScript 타입 에러
**문제**: `request-print` API에서 로고 타입 체크 시 타입 불일치
**원인**: printTypes는 인쇄물만 포함하는데 로고 체크를 하려고 함
**해결**: 로고 체크 로직 제거 (인쇄물 API는 인쇄물만 처리)

### 2. 예상도착일 미표시 문제
**문제**: 모든 제작물에 "영업일 1~2일" 표시
**원인**: 하드코딩된 텍스트
**해결**: 제작물 타입별로 다른 메시지 표시, 예상도착일 DB 필드에 저장
