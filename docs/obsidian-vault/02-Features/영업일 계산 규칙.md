## 🔧 주요 함수

### `isBusinessDay(date: Date): boolean`

날짜가 영업일(평일)인지 확인

```typescript
export function isBusinessDay(date: Date): boolean {
  return !isWeekend(date) && !isHoliday(date);
}
```

### `addBusinessDays(startDate: Date, businessDays: number): Date`

기준일로부터 N 영업일 후의 날짜 계산

**사용 예시**:
```typescript
const today = new Date('2025-10-27'); // 월요일
const after3BusinessDays = addBusinessDays(today, 3);
// 결과: 2025-10-30 (목요일)
```

### `getBusinessDayRange(startDate, minDays, maxDays)`

최소/최대 영업일 범위 계산

**사용 예시**:
```typescript
const orderDate = new Date('2025-10-27');
const range = getBusinessDayRange(orderDate, 2, 3);
// 결과: { min: 2025-10-29, max: 2025-10-30 }
```

### `calculateExpectedArrival(orderDate, productType): string`

발주일 기준으로 예상 도착일 계산

**반환 형식**:
- 단일 날짜: `"2025-10-30"`
- 날짜 범위: `"2025-10-29 ~ 2025-10-30"`

**사용 예시**:
```typescript
const orderDate = new Date('2025-10-27');

// 명함 (2~3일)
calculateExpectedArrival(orderDate, '명함');
// → "2025-10-29 ~ 2025-10-30"

// 자문계약서 (7일)
calculateExpectedArrival(orderDate, '자문계약서');
// → "2025-11-05"
```

### `formatArrivalDate(dateStr: string): string`

날짜를 한국어 형식으로 포맷팅

**사용 예시**:
```typescript
formatArrivalDate("2025-10-29 ~ 2025-10-30");
// → "10월 29일 (화) ~ 10월 30일 (수)"

formatArrivalDate("2025-11-05");
// → "11월 5일 (수)"
```

## 📝 주의사항

1. **년도별 공휴일 업데이트 필요**: 매년 공휴일 데이터를 갱신해야 함
2. **주말 처리**: 토요일(6), 일요일(0) 자동 제외
3. **대체공휴일 포함**: 설날, 추석, 어린이날 등의 대체공휴일 포함
4. **시간대**: 날짜만 고려, 시간은 무시 (한국 시간 기준)
