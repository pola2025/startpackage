# PRD: 자료제출 UI/UX 개선

**문서 버전**: 1.0.0
**작성일**: 2026-01-28
**상태**: Draft

---

## 1. 개요

### 1.1 배경
현재 자료제출 화면은 40개 이상의 필드를 6개 탭으로 구성하여 사용자에게 압도감을 주고 있음.
사용자 여정 관점에서 더 친근하고 단계적인 경험을 제공하여 제출 완료율을 높이고자 함.

### 1.2 목표
- 제출 완료율 향상 (목표: 20% 개선)
- 사용자 이탈 지점 감소
- 파일 업로드 실패 시 명확한 대안 제시
- 민감 정보 입력 시 신뢰도 강화

### 1.3 범위
- Phase 1: 파일 업로드 개선 (이메일 안내 포함)
- Phase 2: 온보딩 화면 추가
- Phase 3: 단계별 마법사 전환 (장기)

---

## 2. 사용자 스토리

### 2.1 파일 업로드 시나리오

#### US-001: 대용량 파일 업로드 시도
```
As a 사용자
When 10MB 초과 파일을 업로드하려고 할 때
Then 이메일로 파일을 보낼 수 있다는 안내를 본다
And mkt@polarad.co.kr 주소가 복사 가능하게 표시된다
```

#### US-002: 지원하지 않는 파일 형식 업로드
```
As a 사용자
When PSD, AI 등 지원하지 않는 형식을 업로드할 때
Then 지원 형식 안내와 함께 이메일 접수 안내를 본다
And 어떤 형식이 지원되는지 명확히 알 수 있다
```

#### US-003: 이메일 접수 안내 확인
```
As a 사용자
When 이메일 접수 안내를 볼 때
Then 이메일 주소를 한 번에 복사할 수 있다
And 이메일 제목/내용 가이드를 볼 수 있다
```

## 3. 기능 요구사항

### 3.1 파일 업로드 유효성 검사 개선

#### FR-001: 파일 크기 검증
| 항목 | 내용 |
|------|------|
| 최대 크기 | 10MB |
| 초과 시 | 이메일 안내 모달/토스트 표시 |
| 이메일 주소 | mkt@polarad.co.kr |

#### FR-002: 파일 형식 검증
| 허용 형식 | 용도 |
|----------|------|
| JPG, JPEG, PNG | 이미지 (사업자등록증, 프로필 등) |
| PDF | 문서 |
| WEBP | 이미지 (압축) |

| 비허용 형식 | 안내 메시지 |
|------------|-----------|
| PSD, AI, EPS | "원본 디자인 파일은 이메일로 접수해주세요" |
| ZIP, RAR | "압축 파일은 이메일로 접수해주세요" |
| 기타 | "지원하지 않는 형식입니다. 이메일로 접수해주세요" |

#### FR-003: 이메일 안내 UI
```
┌─────────────────────────────────────────────────┐
│  📧 이메일로 파일을 보내주세요                  │
│                                                 │
│  파일이 너무 크거나 특수한 형식인 경우          │
│  아래 이메일로 직접 보내주시면 됩니다.          │
│                                                 │
│  ┌─────────────────────────────────────────┐   │
│  │ mkt@polarad.co.kr            [복사]     │   │
│  └─────────────────────────────────────────┘   │
│                                                 │
│  💡 이메일 작성 가이드                          │
│  • 제목: [기수명] 성함 - 파일명                 │
│  • 예시: [25기] 홍길동 - 사업자등록증           │
│                                                 │
│                              [확인]             │
└─────────────────────────────────────────────────┘
```

## 4. 기술 요구사항

### 4.1 파일 검증 로직

```typescript
interface FileValidationResult {
  isValid: boolean;
  error?: {
    type: 'SIZE_EXCEEDED' | 'UNSUPPORTED_FORMAT' | 'OTHER';
    message: string;
    showEmailGuide: boolean;
  };
}

const FILE_CONFIG = {
  maxSize: 10 * 1024 * 1024, // 10MB
  allowedTypes: ['image/jpeg', 'image/png', 'image/webp', 'application/pdf'],
  allowedExtensions: ['.jpg', '.jpeg', '.png', '.webp', '.pdf'],
  emailContact: 'mkt@polarad.co.kr',
};
```

### 4.2 컴포넌트 구조

```
components/
├── ui/
│   ├── file-upload.tsx          # 기존 파일 업로드
│   ├── mobile-file-upload.tsx   # 기존 모바일 업로드
│   └── email-file-guide.tsx     # 신규: 이메일 안내 모달
└── submission/
    └── file-validation.ts       # 신규: 파일 검증 유틸
```

### 4.3 테스트 요구사항

| 테스트 ID | 시나리오 | 예상 결과 |
|----------|---------|----------|
| T-001 | 5MB JPG 업로드 | 성공 |
| T-002 | 15MB JPG 업로드 | 이메일 안내 표시 |
| T-003 | 1MB PSD 업로드 | 이메일 안내 표시 |
| T-004 | 이메일 복사 버튼 클릭 | 클립보드에 복사 |

## 5. UI/UX 명세

### 5.1 이메일 안내 표시 조건

| 조건 | 표시 방식 | 우선순위 |
|------|---------|---------|
| 파일 크기 > 10MB | 모달 (강조) | 높음 |
| 지원하지 않는 형식 | 모달 (강조) | 높음 |
| 파일 크기 > 5MB | 토스트 힌트 (선택적) | 낮음 |

### 5.2 모달 디자인 가이드

- **배경**: 반투명 오버레이 (rgba(0,0,0,0.5))
- **카드**: 흰색, border-radius 12px, shadow-lg
- **아이콘**: 📧 이메일 아이콘 (primary color)
- **이메일 주소**: 강조 박스, 복사 버튼 포함
- **버튼**: Primary 스타일 "확인" 버튼

### 5.3 토스트 메시지 (힌트용)

```
💡 파일이 크면 이메일(mkt@polarad.co.kr)로도 보낼 수 있어요
```
