원활한 진행을 위해 아래 예시대로 구체적으로 요청해주세요

예시 1. 디자인 분위기 표현
✕ 제작 불가
"예쁘고 고급스럽고 깔끔하게 만들어주세요"

→ 주관적 표현만으로는 디자인 방향 특정 불가

✓ 제작 가능
"세리프 폰트 기반 워드마크, 다크네이비(#1a1f36) 단색, 로펌 느낌의 격식 있는 스타일"

→ 유형 + 색상 + 폰트 + 분위기 구체화

예시 2. 시안 개수 요청
✕ 제작 불가
"시안 3~4개 만들어주시면 그중에서 고를게요"

→ 1차 시안은 1개만 제공됩니다

✓ 제작 가능
"심볼마크 1개로 진행, 1차 시안 확인 후 색상 방향만 조정 요청드릴게요"

→ 한 방향으로 집중 후 2회 수정 내에서 정교화

예시 3. 수정 요청 방식
✕ 추가 비용 발생
"처음에 워드마크로 요청했는데 심볼마크로 다시 만들어주세요"

→ 초기 요청사항과 다른 방향은 추가 제작으로 간주

✓ 제작 가능
"워드마크 유지, 글자 간격 조금 좁게 + 컬러를 #1a1f36로 변경"

→ 방향 유지 + 포인트만 수정 = 2회 수정 범위 내
