# Wizard 모드 UX 상세 설계서

**버전**: 1.0.0
**작성일**: 2026-01-29
**작성자**: UI/UX 디자이너 관점
**페르소나**: 45세 소규모 사업장 대표, IT 친숙도 낮음

---

## 1. 현재 문제점 분석

### 1.1 Pain Points

| 문제 | 원인 | 영향 |
|------|------|------|
| **압도감** | 40+ 필드가 4개 탭에 나열 | 첫 화면에서 이탈 |
| **순서 혼란** | "어디서부터 시작?" | 비효율적 입력 |
| **맥락 단절** | 왜 이 정보가 필요한지 모름 | 불안감, 의심 |
| **진행감 부재** | "얼마나 남았지?" | 중도 포기 |
| **실수 불안** | "잘못 입력하면 어쩌지?" | 입력 망설임 |

### 1.2 타겟 사용자 특성

```
김대표님 (45세)
├── 스마트폰 기본 사용 가능
├── 컴퓨터는 익숙하지 않음
├── 긴 양식 보면 답답함
├── "뭐가 필수고 뭐가 선택인지 모르겠음"
├── "중간에 저장되는지 불안함"
└── "한 번에 다 못 채우면 어쩌지"
```

---

## 2. Wizard 모드 설계 원칙

### 2.1 핵심 원칙

1. **한 번에 하나씩** (One Thing at a Time)
   - 한 화면에 1-3개 필드만 표시
   - 인지 부하 최소화

2. **왜 필요한지 설명** (Context is King)
   - 각 필드마다 "이 정보는 ~에 사용됩니다"
   - 불안감 해소

3. **진행 상황 명확화** (Progress Visibility)
   - "Step 3/7" 명확히 표시
   - 예상 소요 시간 안내

4. **실수 방지** (Error Prevention)
   - 다음 단계 전 검증
   - 수정 쉽게 가능

5. **중간 저장 보장** (Auto-save Confidence)
   - 입력할 때마다 자동 저장
   - 저장 상태 명시

## 3. Step 구조 설계

### 3.1 Step 분류 기준

```
필수 Step: 반드시 완료해야 다음으로
├── Step 1: 브랜드 기본 정보 (브랜드명, 업종, 주소)
├── Step 3: 사업자등록증
└── Step 4: 로고 제작 요청

선택 Step: 건너뛰기 가능
├── Step 2: 연락처/계좌 정보
├── Step 5: 명함 스타일
├── Step 6: 프로필 사진
└── Step 7: 마케팅 계정
```

## 4. 마이크로 인터랙션 설계

### 4.1 Step 전환 애니메이션

```css
/* 다음 Step으로 이동 */
.step-enter {
  transform: translateX(100%);
  opacity: 0;
}
.step-enter-active {
  transform: translateX(0);
  opacity: 1;
  transition: all 300ms ease-out;
}

/* 이전 Step으로 이동 */
.step-exit {
  transform: translateX(0);
  opacity: 1;
}
.step-exit-active {
  transform: translateX(-100%);
  opacity: 0;
  transition: all 300ms ease-out;
}
```

### 4.2 Progress Bar 애니메이션

```
Step 변경 시:
1. 진행률 바가 부드럽게 확장 (300ms)
2. 완료된 Step에 체크마크 나타남 (bounce 효과)
3. 현재 Step 숫자 강조
```

### 4.3 자동 저장 피드백

```
입력 중지 후 1초:
├── 저장 아이콘 회전 (saving...)
├── 0.5초 후 체크마크로 변경
└── "✅ 자동 저장됨 (14:32)" 표시
```

### 4.4 필드 포커스 효과

```
포커스 시:
├── 테두리 색상: gray → blue
├── 라벨 색상: gray → blue
├── 도움말 텍스트 살짝 밝아짐
└── 부드러운 확대 효과 (scale 1.01)
```

## 5. 에러 처리 설계

### 5.1 인라인 검증

| 시점 | 동작 |
|------|------|
| 입력 중 | 검증 없음 (타이핑 방해 금지) |
| 포커스 아웃 | 즉시 검증 + 에러 표시 |
| "다음" 클릭 | 전체 검증 + 첫 에러로 스크롤 |

### 5.2 에러 메시지 톤

```
❌ 나쁜 예: "필수 항목입니다"
✅ 좋은 예: "브랜드명을 입력해주세요"

❌ 나쁜 예: "형식이 올바르지 않습니다"
✅ 좋은 예: "이메일 주소 형식으로 입력해주세요 (예: example@email.com)"

❌ 나쁜 예: "파일 크기 초과"
✅ 좋은 예: "파일이 너무 커요 (10MB 이하로 올려주세요)"
```
